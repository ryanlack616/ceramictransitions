# Changelog

## Current Worktree: Materials Workspace Expansion

- Added a shared procedural runtime consumed by both viewers.
- Added compact catalog/table mode with shared filtering, sorting, and selection.
- Added stable material links, material metadata downloads, atom/bond CSV exports, citations, and browser-local bookmarks.
- Added system architecture layer-stack rendering and transition temperature timelines.
- Added structured provenance statuses and Materials Project source records across the catalog.
- Added geometry, stoichiometry, schema, deploy-artifact, performance, parity, accessibility, and headless browser checks.

## Release Notes Policy

- Keep catalog changes and viewer changes in separate bullets when practical.
- Include the catalog version, source revision, validation result, and deployment target for public releases.
- Record scientific caveats and source-status changes explicitly; do not describe procedural or analogue records as exact simulations.
